# MineNalog

Minecraft (Paper 1.21.10) плагин — полная система государства: государственная шахта, казна, магазин, кредиты, паспорта, имущество и налоги.

## Возможности

- **Шахта** — выбор уровней с настройкой налога (% / каждый N-й блок), зоны добычи, генераторы блоков, компас для выхода
- **Казна** — сбор налогов и руд, просмотр в GUI со страницами
- **Магазин** — покупка ресурсов за валюту (по умолчанию булыжник)
- **Кредиты** — выдача, проценты, погашение (`/credit take|info|pay`)
- **Паспорта** — выдача и просмотр (`/passport <Фамилия> <Имя> <Отчество> <ДД.ММ.ГГГГ> <М|Ж>`)
- **Имущество** — покупка участка за полную стоимость или в рассрочку, защита территории, земельный налог
- **Автоналог** — периодическое списание валюты из инвентаря и сундуков
- **Достижения, таблицы лидеров, ежедневный бонус, скорборд**

## Требования

- Java 21
- Paper 1.21.10 (или совместимый)

## Сборка

```bash
mvn clean package
```

Готовый jar появится в `target/MinePlugin-6.0.0.jar`.

## Установка

1. Скопируйте `target/MinePlugin-6.0.0.jar` в папку `plugins/` сервера.
2. Перезапустите сервер (или `/reload`).
3. Настройте `plugins/MinePlugin/config.yml` (координаты шахты, участка, NPC и т.д.).
4. После изменения конфига: `/minereload` (право `mine.admin`).

## Команды

| Команда | Описание |
|---|---|
| `/kazna` | Открыть казну города |
| `/buy` | Магазин ресурсов |
| `/credit <take\|info\|pay>` | Кредитная система |
| `/passport` | Паспорт гражданина |
| `/property` | Имущество (покупка, рассрочка, налог) |
| `/top <mine\|tax\|visit\|ach>` | Таблицы лидеров |
| `/ach` | Достижения |
| `/minereload` | Перезагрузить конфиг |
